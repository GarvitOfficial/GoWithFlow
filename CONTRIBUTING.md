# Contributing to FlowConvert

Thanks for helping make local-first conversion better.

1. Fork the project and create a focused branch.
2. Run `npm install` and `npm run dev`.
3. Keep all conversion work browser-only—no file uploads or runtime conversion APIs.
4. Test the affected source and target files in a current Chromium and Firefox browser where practical.
5. Run `npm run build` before opening a pull request.

Please describe format limitations and expected fidelity in the PR. New converters should include a representative test file or a documented manual test path, without committing sensitive user files.
